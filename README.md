# grind.app: a Y2K-styled Pomodoro timer

A Pomodoro focus timer and task list with an early-2000s desktop look.

**Use it:** https://lionelvlv.github.io/grind-y2k-coded-pomodero/

## Features
- Configurable focus, short-break and long-break lengths
- A task list to track what each session is for
- Settings and tasks saved in `localStorage`
- Alarm sounds generated with the Web Audio API, with no audio files

## Tech
Plain HTML, CSS and JavaScript (`index.html`, `style.css`, `app.js`). No dependencies; hosted on GitHub Pages.
